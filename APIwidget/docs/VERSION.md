## Versioning Guidelines

Documentation follows semantic versioning:

- **Major version (X.0.0)**: Significant structural changes or complete rewrites
- **Minor version (0.X.0)**: New documentation or substantial updates to existing documentation
- **Patch version (0.0.X)**: Minor updates, corrections, or clarifications

## Update Process

When updating documentation:

1. Update the relevant document(s)
2. Update the version number in this file
3. Add a summary of changes to the version history
4. Update the "Last Updated" date in the document header
5. Update the DOCUMENTATION_INDEX.md file if necessary

## Review Schedule

All documentation should be reviewed:

- At the end of each sprint for documents related to that sprint's work
- When substantial changes are made to the related code or process
- At least quarterly for all documents
