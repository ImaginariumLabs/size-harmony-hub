# APIwidget User Guide

## Getting Started

### Creating an Account

1. Navigate to the APIwidget login page
2. Click "Don't have an account? Sign Up"
3. Enter your email address and password
4. Click "Sign Up"
5. Check your email for a verification link
6. Click the verification link to activate your account

### Logging In

1. Navigate to the APIwidget login page
2. Enter your email address and password
3. Click "Sign In"

## Dashboard

The dashboard provides an overview of all your API usage across different providers.

### Dashboard Components

- **Summary Cards**: Quick overview of total API cost, requests, and active providers
- **API Status**: Current status of all your configured API providers
- **Alerts**: Important notifications about your API usage

## Adding API Keys

To start monitoring an API, you need to add your API key:

1. Click "Add API Key" in the header or sidebar
2. Select the API provider from the dropdown
3. Enter your API key
4. Optionally, add a label to identify this key
5. Click "Save API Key"

### Supported API Providers

- **OpenAI**: Monitor token usage and costs for GPT models
- **GitHub**: Track API rate limits and usage
- **AWS**: Monitor AWS API usage (coming soon)
- **Google Cloud**: Track GCP API usage (coming soon)
- **Azure**: Monitor Azure API usage (coming soon)

## Viewing API Details

To view detailed information about a specific API:

1. Click on the provider name in the sidebar
2. View the detailed usage statistics, including:
   - Cost information
   - Request counts
   - Rate limit status
   - Usage trends
   - Recommendations for optimization

## Managing API Keys

To manage your API keys:

1. Navigate to Settings > API Keys
2. View all your configured API keys
3. Add new keys using the "Add New API Key" button
4. Delete existing keys using the delete icon

## Setting Up Alerts

To set up alerts for API usage:

1. Navigate to the provider detail page
2. Click "Set Up Alerts"
3. Configure alert thresholds for:
   - Cost limits
   - Rate limit warnings
   - Quota usage
4. Choose notification methods (email, in-app)
5. Save your alert configuration

## Customizing Your Dashboard

To customize your dashboard layout:

1. Navigate to Settings > Dashboard
2. Drag and drop widgets to rearrange
3. Add new widgets using the "Add Widget" button
4. Remove widgets using the "X" in the corner of each widget
5. Save your layout

## Account Settings

To manage your account settings:

1. Click on your profile picture in the header
2. Select "Profile" or "Settings"
3. Update your profile information
4. Change your password
5. Configure notification preferences
6. Set theme preferences (light/dark mode)

## Troubleshooting

### API Key Issues

If you're experiencing issues with an API key:

1. Verify the key is correct and has the necessary permissions
2. Check if the key has expired or been revoked
3. Try regenerating a new key from the provider's website
4. Delete and re-add the key in APIwidget

### Data Not Updating

If your usage data isn't updating:

1. Click the refresh button on the widget
2. Check if the API provider is experiencing downtime
3. Verify your API key has the necessary permissions to view usage data
4. Log out and log back in to refresh your session

### Account Access Issues

If you're having trouble accessing your account:

1. Use the "Forgot Password" link on the login page
2. Check your email for password reset instructions
3. If you still can't access your account, contact support

## Best Practices

- **Regular Monitoring**: Check your dashboard regularly to stay informed about your API usage
- **Set Up Alerts**: Configure alerts to be notified of unusual activity or approaching limits
- **Secure API Keys**: Never share your API keys and rotate them periodically
- **Optimize Usage**: Use the recommendations provided to optimize your API usage and reduce costs
